Before writing any code, read the relevant skill file first.

| Task domain | When to use                                                                | Skill file                   |
| ----------- | -------------------------------------------------------------------------- | ---------------------------- |
| Frontend    | Pure UI only — components, pages, layouts, styling, no DB or server logic  | `.agents/frontend/SKILL.md`  |
| Backend     | External API server (Go, Python, PHP, etc.) separate from the Next.js repo | `.agents/backend/SKILL.md`   |
| Fullstack   | UI + server logic in one Next.js repo — Route Handlers, Server Actions, DB | `.agents/fullstack/SKILL.md` |

If a task spans multiple domains, pick the dominant one and note the overlap.

If a convention is missing from the skill file, ask before inventing one.
